About

My father had a personal weather station that broke down. With the company no longer manufacturing weather stations, I designed and built a better one using the old station's parts. A new device which allows you view the weather from outside the house.

This is a personal weather station which resides in Provo, Utah. It has been built from spare parts from an older commercial personal weather station. The web-app updates every 2.5 seconds providing you with live updates to the current conditions.

How the station works

As part of a research project, I designed a protocol that would allow many weather stations to join a network of weather stations to provide live updates to anyone to subscribe. This network is created with an MQTT broker that stations will push updates to and clients will listen on.

This weather station is separated into 3 parts: The sensors, the station, and the web-app. An Arduino on the roof is connected directly to all the sensors. Via an RS-232 link, the Arduino communicates with a Raspberry Pi computer which sends the data to a MQTT broker. The web-app—which you are currently on—is connected to the broker as a client saving updates to a database and displaying the current conditions to users.
